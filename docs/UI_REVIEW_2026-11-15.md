Evidence is produced by the Node suite, release-asset build test and Chromium regression against dist. Browser widths: 320, 375, 390, 768, 1024, 1480 and 1920 px. Real public imagery/font assets were retrieved through the configured HTTPS proxy for visual inspection; numerical DEM data came from the bundled clip.

Limitations: the cloud proxy blocked direct Netlify requests before they reached the site. No claim is made that the current live Netlify version was inspected or updated. No real authenticated account operations were performed. The environment network draft includes the Netlify hostname for the outstanding live review.
